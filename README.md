# Apprendii Website

Static multi-page website ready for GitHub and Vercel.

## Publish
1. Upload all files and folders in this project to a GitHub repository.
2. Import that repository into Vercel.
3. Use the default settings. No build command is required.
4. Test the temporary Vercel URL, then add apprendii.com under Project Settings > Domains.

## Updating
Edit the relevant HTML, CSS, or JavaScript file, commit the change in GitHub, and Vercel will redeploy automatically.
